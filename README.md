# CSR Writer v1.1.0

面向 NMPA/CDE 申报的临床试验总结报告（CSR）中文初稿生成工具。
覆盖 I–III 期，按研究设计动态裁剪 ICH E3 骨架，从 TFL 确定性套值，
受控起草正文，合卷输出 annotated / clean 双版本。

> **内部工具，仅限公司内部使用。** 仓库含未公开研究的合成夹具与内部写作规范。

## 它做什么

| 能力 | 说明 |
|---|---|
| **动态骨架** | 按研究设计裁剪章节。单臂开放研究会自动关掉随机化、盲法等 17 节，并留显式声明 |
| **数值零幻觉** | 正文数值一律走占位符，由脚本从 TFL 确定性填充，三道守卫检查无源裸数字 |
| **受控起草** | 方法学章节走「事实卡 → 受约束改写 → 逐项回指校验」；SAE 叙述走逐字预审句 |
| **确定性生成** | 48 个单元零 LLM——目录（Word 域）、表图清单、附录清单、标题页签字位 |
| **双版本输出** | annotated 显示全部缺口与待确认；clean 在缺口未关闭时阻断生成 |
| **排版预检** | 渲染后检查域是否展开、空白页、越界、表格跨页，并出缩略图墙 |

参考产物：[examples/reference/视觉检查示例](examples/reference/视觉检查示例)（含缩略图墙 PNG）

## 它不做什么

这些是设计上的边界，不是未完成项：

- **不生成 TFL 里不存在的数值**——找不到就是缺口，不会推断补全
- **不做个案因果关系判定**——只转述研究者已记录的评价
- **不代写申办方医学综合评价**——永远是人工槽位
- **不合成源文本中不存在的临床经过**——无源时输出固定缺口句
- **不判断资料是否申报就绪**——规则层通过 ≠ 医学/法规批准
- 不替代 QC、QA 稽查，不生成签名页内容
- 不实现 BE 统计内容

排版预检基于 LibreOffice 渲染，与 Word 存在分页和字体回退差异，
是**前置筛查，不替代**在 Word 中更新域后的人工视觉复核。

## 状态与已知限制

**v1.1.0，已冻结。** 312 项回归全绿。

| 限制 | 说明 |
|---|---|
| **从未在真实数据上运行** | 全部证据来自脱敏合成项目。首次真实使用建议按"上线演练"组织 |
| 方法学路径对抗放行率 7.22% | 放行形态是语法破碎的拼接，人工可发现；不是流畅编造 |
| SAE 路径对新写法误伤 100% | 逐字预审句策略的既定代价，安全性最高、自动化最低 |
| 排版 B 类检查误伤 20% | 因此只作警告，不阻断发布 |
| 对抗器是有界文法 | 不是中文语义空间的完备性证明 |
