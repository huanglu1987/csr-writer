# M9 交付说明

## 范围与结论

本轮只完成结构裁剪与装配修正，未开展 M10 内容补强。项目骨架现在由
`study_facts → capability flags → active modules → section_plan → DOCX`
确定性生成，不再全量铺开 E3 章节，也没有建立外用制剂或早期研究的固定目录模板。

脱敏外用研究的实测结果为：

- 119 个 ICH 官方节点与 3 个行业惯例节点合计 122 个；其中 62 个归为无条件核心、35 个归为模块驱动、25 个归为条件省略。实际保留 97 个，另有 9 个正式编号扩展节。
- 指定的 11.4.2.7、11.4.5、11.4.2.3、11.4.2.5、11.4.6 和 16.4 全部消失。
- 另一份肿瘤剂量递增 `study_facts` 已实际渲染为 clean DOCX；两份实际骨架的结构对称差集为 11 个节，仅改 `phase` 标签时差异为空。
- annotated 和 clean 的 OOXML 结构质检均为 `pass`；22 个独立发表编号各有书签和 REF 域。
- 16.0 共输出 22 行状态记录：CSR 必需 6、地区性 8、TMF/按要求提供 3、不适用 5。
- 全量回归 177/177 通过。外部五份只读依据（原始审阅意见及四份临床材料）运行前后 SHA-256 一致。

## 自主设计决定

1. **采用最小正式编号改造。** 新输出使用 11.5“药代动力学评价”、11.6“探索性疗效评价”和 12.7“剂量递增与总体耐受性评价”，未在本轮重命名第 11 章一级标题。这避免在内容层级尚未定稿时引入更大范围的标题迁移。新节全部使用 Heading 样式和稳定书签；11.A/11.B 仅作历史产物回放别名，不会出现在新 DOCX 中。
2. **将局部耐受性放在 12.5.1。** 该位置在“其他安全性观察”下独立容纳主动评分、皮肤体征和已编码为 AE 的用药部位反应，同时不改动 E3 现有 12.6 安全性结论的语义。
3. **源实体编号与发表编号分层。** `T14.3.1.3.3` 等语义键保持不变，经人工确认的一对一映射转为 `T14.3-4` 等发表编号。代表顺序为暴露程度 `T14.3-1`、AE 总体概要 `T14.3-2`、SOC/PT TEAE `T14.3-3`、局部耐受性 TEAE `T14.3-4`；独立的 TRAE 表继续使用后续流水号。这使第 14 章保留 E3 标题语义，又避免正文引用与层级标题冲突。由于存在独立 TEAE/TRAE 表，本轮为每张物理表保留唯一发表号，不合并数值表。
4. **条件节默认物理删除。** 可选的 `retain_not_applicable` 模式会保留标题并写入从事实派生的理由。16.4 是唯一由提交地区策略而非临床事实决定的节，在计划中明确记为 `render_policy.submission_region=CDE`，不伪装成研究事实。
5. **16.1.4 拆分为“名单提交 + CV 留 TMF”。** 同一 E3 附录项的两种材料有不同提交状态，因此在 16.0 中保留两行并明确范围，避免用一个模糊状态覆盖。
6. **clean 版定义为“结构 clean”。** 它不含工具标记、QC 说明或待确认内容，但不代表内容已获医学放行，也不绕过后续 clean 正文的人工门禁。

## 对审阅意见的处置边界

- **未采用固定外用制剂目录。** 审阅者的建议目录仅作验收标准；实现仍由五维 `study_facts` 路由。
- **未重命名第 11 章一级标题。** 本轮采用审阅者提出的最小改动方案；是否将一级标题扩为“临床药理、药代动力学和探索性疗效评价”建议在 M10 内容层级冻结时一并决定。
- **未改造 annotated 版的 Word 批注形态，未补正式 PK 十个子节、10.3 分析集、9.5.x 终点层级、estimand 位置或 AESI/停药 AE 等安全性专项。** 这些均按本轮明确边界留给 M10。

## 遇到的问题

- M6 骨架的全量章节是渲染默认行为，而模块路由只有“增加贡献”。修复时不能简单为模块添加删除动作，否则会使每个模块承担它不知道的全局责任。本轮因此增加独立 section applicability plan，统一决定保留与省略。
- 历史 M3–M8 验收产物中仍保留 11.A/11.B，以便重现已通过的旧里程碑。当前路由、playbook、渲染和交付均已改为正式编号；旧 ID 只能经显式兼容别名读取。
- Word 目录使用真实 TOC 域；具体页码需在 Word 打开文档后更新域。自动化 QC 只在 OOXML 层确认域指令、Heading 级别、书签和 REF 目标完整，未使用 LibreOffice/PDF 转换。

## M10 前建议

1. 由医学撰写人、统计师和发布负责人一次确认正式节号、12.5.1 位置及独立发表号映射，然后锁定结构版本。
2. 在结构版本上再定义 11.5 PK 正式子节、10.3 分析集、9.5.x 终点/estimand 和安全性专项内容合同，避免 playbook 再次迁移。
3. 为第 14 章发表编号增加正式人工确认记录和版本漂移检测，复用 M8 已有的哈希绑定决策模型。
4. 结构复审通过后再将 annotated 标记迁移为 Word 批注，并保持 clean 发布门禁。
