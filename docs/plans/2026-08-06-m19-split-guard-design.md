# M19 分而治之守卫设计

## 目标与边界

本轮只收口守卫线，不做端到端演练、安装文档或最终交付包。30 个
`constrained_llm` 单元按风险分为两条发布路径：

- SAE 叙述 `12.3.2`：继续逐字匹配人工确认的
  `authorized_surface_forms`。
- 方法学 29 个单元：改为有限自由生成，不再要求逐字回放预审句，也不回退到
  M17 的子串守卫。

## 方法学发布守卫

方法学段落按其声明的 `fact_ids` 建立许可表面：

1. 非占位符字段值是不可切分的原子；列表值的每个已声明元素分别为原子。
2. 占位符是不可切分的原子，仍受既有数值和绑定守卫约束。
3. 字段标签可省略。标签一旦出现，后续相邻的值必须属于同一 `fact_id`；二者之间
   只允许标点与经审核的连接词。
4. 扣除整值、合法标签—值对、占位符及连接词后，仍有中文实质内容即硬失败。
5. 否定词、限定反转词、医学实体和实质判断词不得作为连接词。
6. `authorized_surface_forms` 可保留为历史审核资料，但不参与方法学发布判定。

该机制允许“本研究为双盲设计”等标签省略的自然句式，同时阻断字段值切片、
否定插入及“严重程度为已恢复”这类标签—值错配。

## SAE 发布守卫

SAE 路径保持 M18 的逐字预审句边界：多事实段落必须匹配已确认完整句式；缺失临床
经过只能使用固定留槽句；受控因果词、医学负责人留槽、数字及占位符规则不变。
SAE 合法改写的误伤率会单独报告，不以方法学自由度掩盖这一有意的保守取舍。

## 非循环测量

1. 先冻结运行时守卫配置，记录规范化 JSON 与 SHA-256。
2. 冻结后再运行独立留出构造器。构造器只读取移除
   `authorized_surface_forms` 后的事实卡和固定变换任务，不导入守卫模块、不读取
   连接词表、不读取既有成文产物。
3. 留出集覆盖语序调整、分合段、连接词替换、主被动、同义句式和标点变体；每条
   都只使用卡内整值并记录 `fact_ids` 与构造来源。
4. SAE 与方法学分别报告对抗放行率和留出误伤率，不自行设定可接受阈值；所有放行
   样本与所有误伤原句均保留。

## 其余审计项

- 对 34 个 `guarded_section_writer` 单元攻击既有标准化、占位符、绑定、结论条件化、
  数值、语义和文风守卫；单列 `sentence_driven` 零占位符分支结果。
- N5 不原地改写历史 M8 产物。旧 `POP=UNSPECIFIED` 实体从可用映射中退役，生成
  显式迁移记录和待重新解析/人工确认项；在缺少原始语义依据时不猜造替代 POP。
- F8 同时提供结果侧 `matched/result` 与冻结壳侧 `matched/frozen` 分母，并保留其他
  诊断口径但不混称。
- N7 使用不属于现有九张事实卡的新脱敏卡，完整保留候选和放行结果。

## 发布与回归标准

- 方法学路径不得依赖逐字 `authorized_surface_forms`，SAE 路径必须依赖。
- M17 子串模式保持 `release_eligible=false`。
- 只读源文件与夹具哈希不变。
- `python3 -m unittest discover -s tests` 与交付自检必须全绿。
- 新发现问题不筛选，逐条写入 M19 输出目录。
