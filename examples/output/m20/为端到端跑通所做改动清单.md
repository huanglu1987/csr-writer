# M20 为端到端跑通所做改动清单

## 总原则

- 未改动新夹具来迎合现有解析器。
- 未放宽任何数值、正向覆盖、SAE 或结论守卫。
- 所有严格失败现场均保留；继续下游时明确标记为诊断性、不可发布。

## 实际改动

| 发现 | 改动 | 性质 |
|---|---|---|
| 首次编排读取了错误的路由字段层级 | 从 `structure.active_module_ids` 读取；保留 `RUN_ABORTED.json` | 编排脚本修复 |
| SAF 不在旧分析集别名表中 | 支持标题尾部安全 ASCII/英文全称，但非登记名称强制人工确认 | 泛化、未放宽确认闸门 |
| 旧夹具的 `(PKS)` 后还有阶段文字 | 已知标准分析集可在标题中部识别；未知名仍只允许安全尾部提议 | 回归兼容修复 |
| 根级 N/P 行被误入套层启发式 | 在套层推断前优先精确匹配经冻结的语义行 | 结果套值修复 |
| 整张 shell-only 表未进入严格分母 | 新增 `missing_result_entities` 和未解析值位计数，严格模式硬失败 | 加严正确性闸门 |
| CLI `resolve` 未先展开条件化结论 | 在绑定信息存在时先确定性展开，再跑三道数值守卫 | 运行时接线修复 |
| `n_pct` 值本身已含“例”，句式又添加一次 | 条件句式按 cell type 选择单位 | 成文修复 |
| constrained 产物不符合普通 section meta 装配契约 | 增加严格桥接：仅收录正向覆盖和文风均通过、零占位符、段落哈希精确一致的产物 | 装配契约修复，未绕过 resolver |
| M19 冻结测试将历史快照与当前登记表等同 | 只允许 `N4历史数字更正对照.json` 明示登记的 from/to 哈希迁移 | 审计版本迁移修复 |

## 未修改而保留的断点

- shell/result 表集不一致仍硬失败。
- 确定性卷与正文卷仍分开。
- study_facts、tfl_map 和医学结论仍保留人工闸门。
