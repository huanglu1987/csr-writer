# PK 参数

> [合成验收夹具；非临床证据]

PK 参数采用经审核的非房室方法计算，参数分析集按预设纳入和排除规则确定。参数可计算性取决于可定量浓度数据和实际采样覆盖。

低于定量下限的数据按预设规则处理。不可定量结果不等同于无系统暴露，参数解释还需同时核对可定量时点、分析方法定量下限和不能计算的具体原因。

PK 参数分析集中，峰浓度参数汇总结果为 {{T14.2.4.3.1|POP=PKPS|ROW=CMAX|COL=ACTIVE_TOTAL}}，系统暴露参数汇总结果为 {{T14.2.4.3.1|POP=PKPS|ROW=AUC0_T|COL=ACTIVE_TOTAL}}，详见{{@ref:T14.2.4.3.1}}。这些结果只反映当前绑定的参数汇总。

[待医学负责人确认] 参数可计算性及系统暴露的临床解释应结合可定量时点、低于定量下限比例、分析方法定量下限和采样局限综合确认；当前汇总不单独支持对暴露水平作判断。
