# CSR Writer v1.1.0 变更记录

## 新增

- 可选 `visual-qc` CLI：LibreOffice 渲染、PDF 签名校验、A/B 类视觉前置筛查。
- JSON + Markdown 视觉报告，内含强制限制声明。
- 每张最多 20 页的缩略图墙，以红/黄/绿边框显示 A/B/无命中。
- 页眉页脚 story 及跨节继承解析，避免将页眉当作正文越界。
- 配置锁、合法版式留出集、误伤率报告和 B 类升级建议。

## 保持不变

- v1.0.0 起草、数值管线、语义守卫、条件化结论和统一编排逻辑。
- LibreOffice、PyMuPDF 和 Pillow 均不是核心安装依赖。
- 缺少渲染器不阻断流水线，也不改变原有发布判定。
- B 类全部仅警告；最终 Word 人工视觉复核仍是必需闸门。
