# M18 交付说明

## 结论

独立审计的 F1–F9 已按本轮范围修复或明确暴露边界。当前发布路径不再使用
字段子串的自由重组，而是使用经审核的完整断言句式。本结论只表示本轮已测机制未再放行已知攻击，
不表示中文语义攻击已被穷尽。

## 自主设计决定

1. 采纳人工选定的 `authorized_surface_forms` 方案。方案保留自然 CSR 句式，
   同时将多字段的语义组合单元从「词」提升为「整个已审断言」。
2. 不扩大病种实词白名单，也未为降低误伤而放宽连接词。自动攻击发现
   「外」可与「以」组合后，反而删除该单字。
3. 单事实段可直接使用完整源值或固定缺口句；多事实段必须使用已审句式。
   这一界线专门防止标签-值错配。
4. 保留旧子串守卫和未审原子值守卫作为审计重放接口，但两者都是
   `release_eligible=false`，不能写入发布产物。
5. DOCX 在 OOXML/ZIP 层按路径排序重包，条目时间固定为
   `1980-01-01 00:00:00`，不依赖 LibreOffice 或 PDF 转换。
6. 历史别名只允许演示证据或纯缺口输出。已审项目证据不能借父级别名绕过
   120 单元的产出方式登记。
