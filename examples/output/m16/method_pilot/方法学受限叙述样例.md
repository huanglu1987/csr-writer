# M16 方法学受限叙述样例

> 全部内容均为脱敏合成方法事实，不构成临床证据。

# 整体研究设计和计划 - 描述

本研究为随机、双盲、安慰剂对照研究，采用平行组设计。各治疗组按等比例分配，研究实施双盲并设安慰剂对照。

治疗组包括安慰剂组、低浓度组、中浓度组、高浓度每日两次组和高浓度每日一次组。

研究依次经过筛选、随机和连续给药期，随后进入安全性随访期。

# 研究设计的讨论，包括对照组的选择

本研究采用安慰剂对照，研究对象为目标适应证成人受试者。

随机平行组设计用于比较各治疗组的观察结果。安慰剂对照有助于区分治疗变化与疾病自然波动。

# 入选标准

- 受试者自愿参加并签署知情同意书
- 符合方案规定的诊断标准
- 符合方案规定的年龄范围
- 在筛选期内完成评估
- 按方案完成规定检查
- 适用时遵循方案列明的例外条件

# 排除标准

- 存在方案规定的排除性疾病
- 存在研究者判断不宜参加的情况
- 达到方案规定的排除阈值
- 在方案规定时间窗内存在排除情形
- 使用方案列明的禁用药物
- 所有例外均按方案限定条件处理

# 给予的治疗

研究治疗为乳膏剂，提供多种浓度规格，并按组使用相应浓度。

安慰剂组、低浓度组、中浓度组、高浓度每日两次组和高浓度每日一次组均接受皮肤局部外用。

给药频次为每日一次或每日两次，治疗安排覆盖连续治疗期。

# 患者的治疗组分配方法

本研究采用中央随机化，并按等比例分配。分层因素为研究中心和基线严重程度。

区组长度由独立统计师保密保存，随机号由独立统计人员生成。

授权人员通过交互式网络应答系统实施分配。授权人员登录后按顺序取得分配结果。

# 盲法

本研究采用双盲。设盲对象包括受试者、研究者和疗效评价人员。

研究药物在外观和包装上保持一致，盲底由独立人员保管。研究期间维持盲态。

发生需要知晓治疗信息的紧急医疗情形时，授权研究者通过应急揭盲程序提出申请。仅获授权人员可执行揭盲，并保留揭盲记录。

# 主要终点

主要终点为目标量表治疗成功率。按方案规定的量表等级变化判定治疗成功。

在方案规定的主要评价访视判定。按 SAP 规定计算各组治疗成功率，分析集为 FAS。

本研究未采用正式 estimand 框架。
