# 统计分析计划
研究编号：AG-DEMO-01
文件状态：现行有效
# 分析人群及一般统计约定
研究包含两个平行组：甲组、乙组。所有已随机的受试者均进入ITT。至少服用过一次研究药的受试者进入SAF。
安全性分析按实际接受的治疗归组。疗效分析始终按最初随机分配的组别归组。
# 主要疗效分析
主要疗效指标定为第2周功能评分（FUNC）较基线的改变。该量表的取值介于0至10分之间。
基线取随机前3日至随机当日标记为BL的唯一测量。
随机当日为第1天，目标日为第14天，访视窗为第12至16天，取距目标日最近的测量，等距时取较晚者。
按随机组对基线和窗内终点均有测量的观察病例进行描述，缺失不插补，救援后测量保留。
变化量按随访减基线计算，报告均值、样本标准差和观察人数，不作组间推断。
# 安全性分析
TEAE观察窗为首次实际用药日至末次实际用药后2日，含首尾两日。
窗内新发事件及首次用药前已发生而在窗内加重的事件计为TEAE。
按实际治疗组报告发生TEAE的人数、百分比和事件数，同一人同一首选术语只计一人。
按研究者记录汇总严重、致死、药物相关和3级及以上TEAE，相关性待定者单列。
相关性为可能有关、有关计入药物相关，无关不计入，待评估单列。
每人每个实际正剂量给药日记一天，同日多次给药仅计一天，按实际组累加为总用药人日。
