# §11.5.3 低于定量下限（BLQ）数据的处理 playbook

## 适用范围

- 用于说明 BLQ 的定义、处理规则和实际发生情况。
- 适用于单次、多次和稳态阶段。
- 处理规则来自 SAP，实际 BLQ 结果来自 TFL。
- 本节不将 BLQ 解释为无吸收或无系统暴露。

## 给写手的约束（不得写入正文）

- 必须区分给药前 BLQ、给药后 BLQ 和夹在可定量值之间的 BLQ。
- 必须区分浓度汇总与 NCA 计算时的处理规则。
- 不得将 BLQ 默认赋值为零或 LLOQ 的一半。
- 不得根据其他研究的做法补全本项目规则。
- 不得用“未检出”替换 BLQ，除非原始报告如此定义。
- 不得从高 BLQ 比例直接生成“系统暴露低”。
- 不得在正文中提及写手、数据包、绑定、映射或内部状态。
- BLQ 比例、LLOQ、时点和例数必须由数据确定性填充。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- BLQ 数据的实际发生情况待相应统计结果到位后补充。
- BLQ 处理方法尚需依据定稿 SAP 确认。
- 本节仅报告可定量范围内的结果。
- 当前资料不足以判断 BLQ 对 PK 参数估计的影响。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`和其他“XX 性为”。
- 「经审核」「按预设」各自每节至多 1 次。
- “按预设”只用于明确 SAP 中已规定的处理。
- 每段至多 1 个分号。
- 单句不超过 60 字。
- 边界声明集中放在段末。
- 先写规则，再写实际 BLQ 情况，最后写影响。
- 避免连续使用“不得”类防御句式作为正文。

## 1. 本节的权威依据

- ICH E3 §9.5.4 要求说明药物浓度测定方法。
- ICH E3 §11 要求结果呈现与计划的统计方法对应。
- ICH E3 Q&A Q1/Q4 支持对临床药理结果扩展正式小节。
- 国家药监局2019年第88号公告是已验证的中国实施依据。
- 本节由 M-PK-NCA 或 M-TOPICAL-PK 模块激活。
- BLQ 规则的真相源是定稿 SAP 和生物分析报告。
- BLQ 实际结果的真相源是已确认 TFL。
- 核查表未验证的专项文号不在本节自行补入。

## 4. 数值红线与结论性表述规则

- LLOQ、BLQ 比例、例数、时点和浓度均使用占位符。
- 即使 BLQ 在 SAP 中以零参与计算，正文也必须说明测量状态。
- “半数”“多数”“大部分”不得替代已绑定比例。
- 不得用中文约数、分数或倍数绕过数值守卫。
- 不得将不可计算参数自动判定为暴露低。
- 不得将可定量时点数直接解释为采样完整。
- 本节只描述 BLQ 对结果的可观察影响。
- 结论性判断由 11.5.10 的数据条件化规则处理。
- 关键来源缺失时，不生成暴露判断句。
- 表号只使用 `{{@ref:...}}`。

- 无稳态阶段时删除对应段落。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 未报告 LLOQ | 与分析物、基质和方法版本一并说明 |
| 不说明 BLQ 分母 | 每个比例绑定明确分母 |
| 将 BLQ 当作零暴露 | 区分计算赋值和测量状态 |
| 不区分汇总与 NCA 规则 | 分两段写明各自用途 |
| 参数无法计算却不说原因 | 绑定可定量点数和具体原因 |
| 用“未检出”掩盖 BLQ | 保留 BLQ 术语并说明 LLOQ |
| 把 D1 与 D28 的 BLQ 混在一起 | 按 STAGE 维度分段呈现 |
| 由高 BLQ 比例推导无安全性风险 | 限定本节为方法和数据描述 |

## 7. 本节特有的易错点

- BLQ 可以出现在可定量值前、之间或之后，处理可不同。
- 给药前 BLQ 的处理不能自动套用到给药后。
- 连续 BLQ 对终末相估计的影响可大于单个 BLQ。
- 同一分析物在方法变更后可能有不同 LLOQ。
- 使用实际时间计算 NCA 时，BLQ 位置也应按实际时间判定。
- 样本数与受试者数是两个不同分母。
- 可定量时点数不等于可计算参数数量。
- “多数 BLQ”必须还原为精确比例后才可使用。
- BLQ 不得用于推断局部组织暴露。
- 本节不做生物分析方法的合规结论。
