# §11.5 药代动力学评价——外用制剂低系统暴露 playbook

> 用于 `M-TOPICAL-PK`。这不是系统给药 PK 模板：目的是描述和界定
> 系统暴露，不得预设暴露已被证明“足够低”。

## 最低输入

- 外用给药方案事实：涂布部位/面积、用量、浓度、频次和采样时点。
- 经审核的 PK 浓度表、BLQ 规则和适用的 NCA 结果。
- PK 浓度集/PK 参数集的定义。

## 必答问题

- 外用暴露条件和采样设计是什么。
- 多少样本可定量、BLQ 如何处理，是否可计算 PK 参数。
- 数据能支持的只是暴露陈述，还是经人工确认的有限结论。

## 硬约束

- 不得沿用系统给药的“充分表征 PK”或剂量比例性预设。
- 不得将 BLQ 或无法计算改写为“无系统暴露”。
- 任何“未检测到”或“系统暴露低”的表述均不得单独出现；同一结论段必须逐项交代：
  BLQ 比例、哪些采样时点存在可定量结果、Cmax/AUC 等参数能否计算、不能计算的
  具体原因、生物分析方法的 LLOQ，以及这些事实对结论外推的限制。任一来源缺失时
  必须登记 `source_gap`，不得用概括性结论替代。
- BLQ 比例、可定量时点、LLOQ、Cmax/AUC 的可计算状态及不能计算原因必须分别绑定
  到经确认的方案/SAP/TFL 证据；不得从“多数为 BLQ”推导为“无吸收”或“无风险”。
- 所有浓度、时间、比例和 PK 参数一律使用占位符。
- 表、图只能使用 `{{@ref:...}}` 交叉引用占位符，不得写死编号。
- 对暴露是否“低”或是否有临床意义不作自主判定。

## 溯源

逐段记录方案/SAP 定位、TFL 语义键、BLQ 规则、分析集及人工确认状态。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §9.5.4 要求说明药物浓度测定。
- ICH E3 Q&A Q1/Q4 允许对 E3 未详细规定的临床药理内容设置正式扩展节。
- 当前结构将外用制剂 PK 放入 11.5，并由 `M-TOPICAL-PK` 路由激活。
- 第14章的 PK 表类别由 `M-PK-NCA`/`M-TOPICAL-PK` 驱动，无 PK 研究不出现该类别。
- 国家药监局2019年第88号公告确立 ICH E3 中国 CSR 基线。
- CDE 申报要求核查表已确认 I 期 PK 研究报告通常归 CTD 5.3.3；本节不自行决定申报定位。
- 本项目中浓度、NCA、BLQ 和 LLOQ 的真相源是已确认方案、生物分析报告、SAP 和 TFL。
- 核查表没有确证的专项指导原则文号不得凭印象补入。

## 4. 数值红线与结论性表述规则

- 浓度、LLOQ、BLQ 比例、时点、PK 参数和个体数必须使用占位符。
- 实际暴露倍数、蓄积比和剂量比例性估计不得用中文倍数表述规避守卫。
- `t1/2`、`AUC0-∞`、`AUC0-t` 等是参数 token，不是数值白名单。
- 计划采样时点和给药频次是方案事实，仅通过 facts 白名单。
- “未检出”必须绑定具体分析物、时点、LLOQ 和实际结果。
- “无系统暴露”不得由 BLQ 或不可计算自动推导。
- “系统暴露低”仅能在全部关键绑定完整时生成，并标 `[待医学负责人确认]`。
- 有可定量数据但参数无法计算时，必须先陈述原因，再给限制性措辞。
- 关键绑定缺失时不生成判断句，改为数据待到位提示。
- 不得由低暴露推导无安全性风险、无 DDI 或不需剂量调整。

## 5. 推荐段落结构

- [段1] PK 目的、分析集和外用暴露条件：2–4 句。
- [段2] 采样设计与生物分析方法：包含 LLOQ，3–5 句。
- [段3] BLQ 和可定量情况：按阶段与时点提炼，3–6 句。
- [段4] 浓度-时间结果：分单次与稳态阶段，3–6 句。
- [段5] PK 参数及可计算性：对 Cmax、AUC、Tmax、t1/2 分别说明，4–7 句。
- [段6] 多次给药蓄积和稳态：仅在有预设分析时写，3–5 句。
- [段7] 剂量比例性或幂函数模型：报估计、区间和模型限制，3–6 句。
- [段8] 给药面积、部位或皮肤状态影响：预设时才写，2–5 句。
- [段9] 个体异常与采样/用药偏离：客观陈述，2–4 句。
- [段10] 数据条件化 PK 结论：同时交代 BLQ、可定量、参数、LLOQ 和限制，3–6 句。
- 每段不超过 7 句；不复制全部时点和全部参数表。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 只写“未检出”，没有 LLOQ | 绑定生物分析方法的 LLOQ 并说明分析物/基质 |
| 只写“暴露低”，没有 BLQ 比例 | 强制报告 BLQ 分母、时点和可定量情况 |
| 参数不可计算但没写原因 | 区分采样不足、可定量点不足、曲线不完整等已确认原因 |
| 将 D1 与 D28 数据混成一个 PK 结果 | 保留 `STAGE` 维度并分段呈现 |
| 四个浓度/频次组列被合并 | 列 ID 同时编码浓度和频次，不使用模糊 Active |
| 无法估计剂量比例性却写成“线性” | 报模型估计、区间和数据限制，不自主判定 |
| 用 BLQ 推导无吸收或无风险 | 将测定限制与生物学/临床解释分开 |
| 个体异常值被平均值遮蔽 | 引个体曲线并记录预设异常审查 |

## 7. 本节特有的易错点

- 外用制剂 PK 的结论方向是界定系统暴露，不是预设充分表征全身 PK。
- BLQ 不等于数值为零，不得在计算或文字中默认为零。
- LLOQ 是方法性能参数，必须绑定具体分析物、基质和方法版本。
- 一个受试者有可定量点不等于该受试者可计算 AUC 或终末相参数。
- 稳态阶段名称不能代替“已达稳态”的数据判定。
- 蓄积比必须说明基于 Cmax、AUC 还是其他指标。
- 幂函数模型的斜率点估计与线性结论不是同一层信息。
- 涂布面积、实际用量和皮损完整性可同时影响暴露，不得只用标称浓度解释。
- 采样时间偏离可影响 Tmax/Cmax，应与实际时间数据一起审查。
- “无临床意义”是医学判断，不由 PK 写手单独生成。
