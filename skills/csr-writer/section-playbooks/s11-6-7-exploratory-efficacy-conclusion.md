# §11.6.7 探索性疗效结论——数据条件化 playbook

> 适用于研究目的和分析定位为探索性的疗效评价。
> 本节不得采用确证性语气，即使预设分析包含假设检验。

## 适用范围

- 早期研究中的探索性临床终点。
- 皮肤科量表、感染学终点或其他由领域模块激活的探索性终点。
- 可含预设假设检验，但检验存在不改变探索性定位。
- 非预设分析必须明确其补充或事后性质。
- 结论由 `EXPLORATORY_EFFICACY_CONCLUSION_V1` 确定性展开。

## 最低输入

- 方案明确的探索性目的和终点层级。
- SAP 中分析集和分析方法的预设状态。
- 主要探索性终点的经审核结果。
- 使用的分析集名称。
- 分析是否预设的结构化判定。
- 是否实施假设检验的结构化判定。
- 支持性 TFL 的已确认表号。

## 给写手的约束（不得写入正文）

- 只输出已允许的结果占位符和结论 token。
- 不得把统计显著改写为临床有效或确证成功。
- 不得使用“证实”“确证”“疗效优于”或“达到主要终点”等措辞。
- 不得自行判断分析是否预设或是否为事后分析。
- 不得在正文出现写手、模型、证据包、绑定、映射、占位符或置信状态。
- 不得把禁止事项转述为研究事实。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节探索性疗效结果待相应统计结果到位后补充。
- 本节结论基于预设探索性分析，未涵盖未预设的补充分析。
- 现有资料不足以形成探索性疗效判断。
- 上述结果仅作探索性解释，不用于确证性结论。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §8 要求研究目标与报告结果对应。
- ICH E3 §9.5 要求预先定义疗效和安全性变量。
- ICH E3 §11.4.1 要求报告疗效分析、点估计和区间等结果。
- ICH E3 §11.4.2 要求说明统计和分析问题。
- ICH E3 §11.4.7 承接疗效结论；当前结构将探索性结论置于 11.6.7。
- ICH E3 Q&A Q1/Q4 允许按研究设计重排和新增正式章节。
- ICH E3 §13 要求总体讨论不引入前文未报告的新结果。
- 国家药监局 2019 年第 88 号公告确立 ICH E3 中国 CSR 结构基线。
- CDE 2021 年第 63 号相关指导原则要求分析方法和数据源保持一致。
- 规格 §1.2 禁止工具自主形成最终获益风险结论。
- 规格 §1.2.1 要求结论性措辞由数据条件确定。
- 规格 §3 要求统计数值只能由 datapack 确定性填充。

## 2. 必须回答的问题清单

- 本节对应的研究目的是否明确为探索性。
- 主要探索性终点是什么。
- 使用哪个分析集。
- 终点结果是否已有经审核来源。
- 分析是否在方案或 SAP 中预设。
- 是否实施了假设检验。
- 假设检验是否仅作探索性解释。
- 是否存在 FAS 与 mFAS 平行结果。
- 两个分析集的结果是否分别呈现。
- 是否存在协变量校正分析。
- 协变量是否在 SAP 中预设。
- 是否存在敏感性分析。
- 是否将补充分析标明为非预设。
- 是否避免“证实”类确证性措辞。
- 是否避免把 p 值等同临床意义。
- 关键角色缺失时是否取消判断句。
- 结论是否保留医学负责人确认标记。

## 3. 源文件 → 内容映射

| 内容 | 方案来源 | SAP 来源 | TFL 来源 | 受控角色 |
|---|---|---|---|---|
| 探索性目的 | 方案研究目的章节 | SAP 分析定位 | 不适用 | 源片段 |
| 终点定义 | 方案 9.5.x 或项目等价章节 | SAP 终点定义 | 表标题与脚注 | `primary_endpoint_result` 上游 |
| 分析集 | 方案分析集原则 | SAP 分析集定义 | 表标题中的 FAS/mFAS | `analysis_set` |
| 预设状态 | 方案/SAP 分析清单 | SAP 正文与修订记录 | 不适用 | `prespecified` |
| 假设检验 | 方案统计假设 | SAP 检验方法 | p 值或模型表 | `hypothesis_test` |
| 皮肤科量表 | 方案量表章节 | SAP ANCOVA 章节 | 表14.2.2.x 系列 | 主要结果来源 |
| 协变量校正 | 方案基线变量 | SAP ANCOVA 模型 | 表14.2.2.x ANCOVA | 支持性结果 |
| 敏感性分析 | 方案缺失处理 | SAP 敏感性分析 | 对应支持表 | 支持性结果 |

- 表14.2.2.1.1 与 .1.2 等 FAS/mFAS 平行表不得交换分析集。
- 版式继承只继承网格，分析集必须从各自标题确认。
- IGA、红斑、鳞屑、WI-NRS 和 DLQI 等终点必须按方案名称呈现。
- 每个终点的基线值、变化值和协变量校正结果不得混为一个角色。
- 事后分析若无 SAP 定位，必须明确标记为非预设。

## 4. 数值红线与结论性表述规则

- 主要终点结果必须使用 `primary_endpoint_result` 完整占位符。
- 分析集必须使用 `analysis_set` 对应的经审核文字结果。
- 预设状态必须使用 `prespecified` 的结构化判定。
- 假设检验状态必须使用 `hypothesis_test` 的结构化判定。
- 四个角色必须在结论 token 前逐一陈述。
- 写手看不到结构化取值，不得选择分支。
- 预设且无假设检验时，脚本生成描述性探索性限定。
- 预设且含假设检验时，脚本仍生成“不用于确证性结论”的限定。
- 非预设时，脚本明确为补充探索性结果。
- 任一关键角色缺失时，不生成疗效判断。
- 不得从 p 值自动生成“有统计学意义”。
- 不得从组间差异自动生成“临床相关”。
- 不得使用“疗效确切”“显示优于”或开发建议。
- 结论 token 段固定保留 `[待医学负责人确认]`。

## 5. 推荐段落结构

- [段1] 重述探索性目的、终点和分析集，1–2 句。
- [段2] 主要探索性结果，2–4 句，引用支持表。
- [段3] FAS/mFAS 或其他分析集的一致与差异，2–4 句。
- [段4] 协变量校正、敏感性或补充分析，2–4 句，仅在预设时呈现。
- [段5] 结论 token 展开的探索性限定，1–2 句。
- 结果段只提炼回答研究目的所需的少量关键结果。
- 不逐行抄录全部量表和访视结果。
- 分析集差异明显时先陈述事实，不解释原因。
- 非预设分析放在预设分析之后，并明确其性质。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 探索性研究使用确证性措辞 | 条件规则所有分支均保留探索性限定 |
| p 值存在即写“证实有效” | 假设检验状态不改变研究定位 |
| FAS 与 mFAS 结果混写 | 分析集角色分别从表标题确认 |
| 事后分析未标注 | `prespecified=false` 自动进入补充探索性分支 |
| 只报告有利终点 | 按方案终点清单核对，不选择性呈现 |
| 量表版本或方向错误 | 从方案和 SAP 核对量表版本及高低分含义 |
| 协变量未预设仍解释 ANCOVA | 无 SAP 定位时标为非预设 |
| 基线差异被当作疗效结果 | 基线和变化值角色严格分开 |
| 敏感性结果不一致被淡化 | 先陈述不一致，再留给医学和统计审核 |
| 结论引入前文未陈述结果 | 四个结论角色必须先出现 |

## 7. 本节特有的易错点

- “主要探索性终点”不等同“确证性主要终点”。
- 研究标题中的 I 期、II 期或 III 期标签不参与结论路由。
- 使用 ANCOVA 不自动使分析成为确证性分析。
- 使用 p 值不自动使结果成为确证性证据。
- FAS/mFAS 同构表仍可能因分析集纳入规则产生不同结果。
- 量表治疗成功定义可能包含多个组成条件，不得只取其中一个。
- 缺失数据处理不同可能改变分母，正文必须沿用 SAP。
- 多重终点未控制多重性时不得选择性解释显著结果。
- 非劣效或等效性措辞只有相应模块激活时才允许。
- 皮肤科评分的改善方向必须核对量表定义。
- 微生物学治愈与临床治愈不得互换。
- PRO 结果不得由研究者量表替代。

## 8. 发布前检查

- 四个条件角色顺序与契约一致。
- 所有统计值均为占位符。
- 表号均为交叉引用占位符。
- 结论 token 只出现一次。
- 未出现确证性越权措辞。
- 非预设分析已明确标识。
- 未出现内部流程语言。
- 缺失分支没有疗效判断。
- 医学负责人确认标记保留。
- 元数据可追到方案、SAP 和 TFL。
