# §12.1 暴露程度 playbook

## 目的

按经审核的安全性分析集和 TFL 描述研究治疗的给药持续时间、给药次数、累计用量、
剂量强度或依从性等已预设暴露指标。不得把暴露情况自行解释为安全或可耐受。

## 最低输入

- 经审核的暴露指标定义及其分析集；
- 与正文陈述一一对应的暴露汇总 TFL 语义键；
- 已确认 TFL 映射中的表号交叉引用。

## 硬约束

- 所有结果数字一律使用已审核占位符；不得输出裸数字或中文约数。
- 表号只使用 `{{@ref:...}}`，不得写死。
- 缺少结果来源时保留 `source_gap`，不得把“未提供”改写成“未发生”。
- 不根据暴露汇总自主下耐受性、剂量充分性或获益风险结论。

## 给写手的约束（不得写入正文）

- 暴露指标、分母和分析集沿用经审核定义，不得自行换算或合并。
- 不得在正文出现 source-gap、映射、绑定、占位符或生成流程。
- 结果不足时只选用下一分区标准句，不得推定为未暴露或暴露充分。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节研究治疗暴露情况待相应统计结果到位后补充。
- 本节给药持续时间及累计用量情况待相应统计结果到位后补充。
- 现有资料不足以评价实际暴露程度及其对安全性解释的影响。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §12.1 要求从暴露人数、暴露时长和剂量三维描述暴露程度。
- ICH E3 §12.1 默认所有至少接受一次研究治疗者进入安全性集，不同时须说明。
- ICH E3 §12.1 与 16.2.5 受试者用药/暴露数据可交叉追溯。
- 国家药监局2019年第88号公告确立 ICH E3 中国 CSR 基线。
- CDE 2021年第63号数据管理和统计分析相关指导原则支持暴露算法、分析集和数据源一致性。
- 2020年第57号《药物临床试验质量管理规范》第五十五条要求源数据与报告一致。
- 暴露、剂量强度和依从性定义必须以已确认 SAP 和给药数据为真相源。
- 本节不引入核查表未验证的暴露或依从性法规文号。

## 2. 必须回答的问题清单

- [ ] 暴露分析使用哪个分析集。
- [ ] 受试者按实际治疗还是随机治疗计组。
- [ ] 是单一治疗期还是多期、交叉或扩展期。
- [ ] 实际接受研究治疗的受试者人数是什么。
- [ ] 暴露时长的起止和计算规则是什么。
- [ ] 给药次数、疗程数或用药天数如何定义。
- [ ] 累计剂量或用量的单位和算法是什么。
- [ ] 剂量强度、相对剂量强度或依从性是否预设。
- [ ] 计划暴露与实际暴露是否分开。
- [ ] 减量、暂停、延迟和永久停药是否反映在暴露中。
- [ ] 外用制剂实际用量、涂布面积和部位是否可评估。
- [ ] 吸入或眼用制剂的设备或给药单元如何换算。
- [ ] 是否存在跨组给药或实际制剂与随机组不符。
- [ ] 暴露表与 10.1 实际给药人数是否一致。
- [ ] 暴露表与 12.2 安全性分母是否一致。
- [ ] 是否有足以影响安全性解释的暴露差异。
- [ ] 上述影响是否有已确认医学或统计评估。
- [ ] 正文是否只按关键指标提炼。

## 4. 数值红线与结论性表述规则

- 暴露人数、时长、次数、剂量、用量、强度和依从性全部使用占位符。
- 分位数、范围、标准差和组间差异也必须追溯。
- 计划剂量和频次仅由 protocol_facts 白名单引入。
- 实际暴露不得用计划暴露补全。
- “暴露充分”“暴露相当”和“依从性良好”是判断性表述。
- 需要结论时，必须定义预设界值、绑定实际结果并标 [待医学负责人确认]。
- 暴露差异对安全性的影响不由本节写手自主推断。
- 源缺失时不生成“未减量”“未中断”或“无过量”。
- 表图仅使用受控交叉引用占位符。

## 5. 推荐段落结构

- [段1] 暴露分析集、实际治疗计组和给药设计，2–4 句。
- [段2] 暴露人数与治疗期覆盖，2–4 句。
- [段3] 暴露时长和给药次数，3–5 句。
- [段4] 累计剂量或用量与剂量强度，3–5 句。
- [段5] 减量、暂停、延迟或永久停药，3–6 句。
- [段6] 依从性或与计划暴露的差异，2–5 句。
- [段7] 暴露对安全性解释的已确认限制，1–3 句。
- 正文不重复所有分位数和全部组列。
- 多期研究分期写，不把期数当受试者数。
- 外用制剂优先报实际用量、面积和频次完成度。
- 每段最多 6 句，完整分布留在支持表。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 只写实际给药人数 | 强制人数、时长和剂量三维输入 |
| 安全性集与实际给药人数不一致 | 与 10.1/10.3 对账 |
| 计划剂量被当作实际剂量 | 分开 facts 与 datapack 溯源 |
| 多期数被当受试者数 | 使用 PERIOD 维度与受试者账户分开 |
| 外用制剂只报标称浓度 | 审查实际用量、面积、部位和频次 |
| 剂量强度公式或分母未说明 | 从 SAP 引用算法和单位 |
| 暴露差异被解释为安全性差异 | 只陈述已确认分析 |
| 逐人暴露清单泄露识别信息 | 只做表级元数据和受控引用 |

## 7. 本节特有的易错点

- 暴露时长可按日历日、实际给药日或疗程计算。
- 累计剂量对外用制剂可为质量、制剂量或活性成分量。
- 频次降低、暂停和永久停药是不同后果。
- 实际治疗计组可与随机计组不同。
- 依从性分子、分母和可接受范围必须来自 SAP/方案。
- 暴露表与 AE 表分母差异不一定是错误，但必须可解释。
- 暴露不足可限制安全性解释，但不能由写手自主认定。
- 预设剂量可调整时，必须绑定实际路径。
- 清单 16.2.5 可作反向追溯，但不应带入受试者标识。
- 本节“暴露”是给药暴露，不是 PK 系统暴露。
