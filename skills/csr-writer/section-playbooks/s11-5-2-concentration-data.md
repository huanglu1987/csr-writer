# §11.5.2 血药浓度数据 playbook

## 适用范围

- 用于呈现各阶段、时点和治疗组的血药浓度。
- 本节不替代 BLQ 专节、PK 参数专节或 PK 结论。
- 外用制剂的目的是界定系统暴露，不预设暴露为低。
- 单次给药与稳态阶段必须分开呈现。

## 给写手的约束（不得写入正文）

- 只能使用当前节提供的浓度键、采样事实和交叉引用。
- 不得把 BLQ 改写为零、未吸收或无系统暴露。
- 不得在时点之间内插浓度。
- 不得根据图形自行判定峰值或稳态。
- 不得将计划采样时间当作实际采样时间。
- 不得将不同分析物、基质或方法版本的结果合并。
- 不得在正文中出现写手、证据包、绑定或占位符等内部词。
- 所有浓度、时间和例数都必须由数据包确定性填充。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节各采样时点的血药浓度待相应统计结果到位后补充。
- 当前资料不足以完整描述浓度-时间变化。
- 本节结果仅覆盖已有可定量结果的采样时点。
- 实际采样时间尚未完成核对，相关解释受到限制。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`和其他“XX 性为”。
- 「经审核」「按预设」各自每节至多 1 次。
- 每段至多 1 个分号。
- 单句不超过 60 字。
- 边界声明放在段末，不逐句附加免责表述。
- 优先写“在 X 时点，Y 组的浓度为 Z”。
- 不连续罗列所有时点，详细数据留在表图。
- 单次与多次给药分段表述。

## 1. 本节的权威依据

- ICH E3 §9.5.4 要求说明药物浓度测定方法。
- ICH E3 §11 要求将已分析结果与方法和人群对应。
- ICH E3 Q&A Q1/Q4 允许为临床药理结果设置正式扩展节。
- 国家药监局2019年第88号公告是已验证的中国实施依据。
- 本项目 11.5.2 由 M-PK-NCA 或 M-TOPICAL-PK 模块激活。
- 无 PK 评价的研究不应出现本节。
- 浓度的真相源是生物分析结果和已确认 TFL。
- 任何未验证的 CDE 文号保持待核实。

## 4. 数值红线与结论性表述规则

- 浓度、时间、例数、变异系数和 LLOQ 全部使用占位符。
- 计划采样时点只可通过方案事实白名单呈现。
- 实际时点属结果数据，必须取自已确认数据。
- 不可定量结果不等于浓度为零。
- “较低”“较高”或“峰值”均需要明确比较或时间依据。
- 不得根据均值补写个体浓度。
- 不得由浓度趋势自动产生稳态、蓄积或线性结论。
- 本节不生成“系统暴露低”的判断句。
- 结论性表述留给 11.5.10 的数据条件化规则。
- 表号和图号使用交叉引用占位符。

## 5. 推荐段落结构

- [段1] 说明分析物、基质、分析集和阶段，3–4 句。
- [段2] 概述采样时点和实际覆盖，3–5 句。
- [段3] 呈现单次给药后的关键浓度变化，3–6 句。
- [段4] 呈现稳态阶段的关键浓度变化，3–6 句。
- [段5] 对照图表说明可定量时点，2–4 句。
- [段6] 客观说明明显异常值或采样偏离，2–4 句。
- [段7] 段末说明数据覆盖和 BLQ 对解释的限制。
- 每段优先提炼 1–3 个关键结果。
- 不逐项复制每个时点的完整表格。
- 无稳态阶段时，不生成第4段。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 不说明分析物和基质 | 在首段锁定方法对象 |
| 将计划时间当作实际时间 | 分开引用方案与实际记录 |
| 只写“未检出” | 同时说明 LLOQ、BLQ 和可定量时点 |
| 将 BLQ 当作零 | 保持方法状态，不转换为数值零 |
| 将 D1 与 D28 混合 | 保留 STAGE 维度并分段写 |
| 治疗组合并后丢失频次 | 列 ID 同时保留浓度和频次 |
| 从图形自行判定稳态 | 只呈现可核对的时点和浓度 |
| 正文抄入全部时点 | 只提炼关键结果并引表图 |

## 7. 本节特有的易错点

- 浓度低于 LLOQ 是测量状态，不是生物学不存在。
- 浓度均值的分母可随时点变化。
- 几何均值通常不包含无法对数转换的值。
- 必须说明实际采样时间是否用于参数计算。
- 外用给药的实际涂布量和面积可影响浓度。
- 皮损完整性可影响暴露，但只在有分析时呈现。
- 稳态阶段名称不代表已经证实达到稳态。
- 峰值时点必须由实际数据决定。
- 不同分析方法版本的 LLOQ 不得混用。
- 本节不推导暴露是否有临床意义。
