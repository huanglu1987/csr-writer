# §11.2 人口学与基线特征——受控执行 playbook

## 范围

- 描述经审核分析集中的人口学和基线特征汇总。
- 不把基线差异自动解释为可比、不平衡或影响疗效。
- 特殊人群变体仅在模块路由激活时使用共享专项 playbook。

## 最低输入

- 经审核的分析集定义、人口学变量和基线变量定义。
- 对应汇总 TFL 的语义键与交叉引用实体。

## 硬约束

- 年龄、性别构成、基线评分及组间结果一律使用取值占位符。
- 表号只能使用 `{{@ref:...}}`，不得写成正文数字。
- 不从缺失变量推断人群特征，不自主判断基线可比性。
- 结论性解释必须标记待医学或统计负责人确认。

## 溯源

逐段记录变量定义、分析集、TFL 语义键、置信度和人工确认状态。

---

## 给写手的约束（不得写入正文）

- 不得把基线变量缺失写成组间可比，也不得从疾病名称补出未提供特征。
- 不得转述占位符、映射、绑定或人工确认流程。
- 证据不足时只选用下一分区的标准表述，不另造限制性措辞。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节人口学特征待相应统计结果到位后补充。
- 本节基线疾病特征待相应统计结果到位后补充。
- 现有资料不足以评价治疗组间的基线分布，未作进一步解释。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §11.2 要求呈现人口学和其他基线特征。
- ICH E3 要求对治疗组之间的基线特征进行可审查的汇总，但不授权自动下“可比”结论。
- ICH E3 第14章支持 14.1.x 人口学和基线表。
- 国家药监局2019年第88号公告确立 ICH E3 基线。
- CDE 2021年第63号数据管理和统计分析相关指导原则支持分析集、数据处理与可追溯性。
- ICH E9(R1) 在中国的实施依据为国家药监局2021年第16号公告；若基线变量与 estimand 有关，仅按已确认 SAP 转述。
- 人口学变量、基线定义和统计量的真相源为方案、SAP 和已确认 TFL。
- 未核实的 WHODrug 或其他字典“法定强制”说法不写入本节。

## 2. 必须回答的问题清单

- [ ] 本节使用哪个分析集，与 10.3 是否一致。
- [ ] 年龄、性别和其他人口学变量的定义是什么。
- [ ] 年龄使用连续统计、分类统计还是两者。
- [ ] 性别、种族、族群或地区信息是否在项目中收集。
- [ ] 基线体格、生命体征和疾病严重程度变量是什么。
- [ ] 每个疗效终点的基线值如何定义。
- [ ] 临床相关的病程、既往治疗和合并疾病是否需呈现。
- [ ] 基线时间点是签约、首次给药前还是随机前最后一次非缺失值。
- [ ] 重复测量时基线值的选择规则是什么。
- [ ] 统计量是均值/标准差还是中位数/范围，是否与 SAP 一致。
- [ ] 类别变量的分母是总分析集还是非缺失者。
- [ ] 缺失基线值的人数和处理是什么。
- [ ] 是否存在极端或临床不合理值，如何经数据审核处理。
- [ ] 是否需分 FAS 和 mFAS 平行呈现。
- [ ] 特殊人群的年龄或生理特征是否触发共享专项 playbook。
- [ ] 任何基线差异是否仅客观陈述，没有自动解释。
- [ ] 数据与相应疗效模型中的协变量是否可追溯。
- [ ] 表号是否来自已确认发表映射，而非 ICH 章节号。

## 4. 数值红线与结论性表述规则

- 年龄、体重、身高、BMI、病程、基线评分和所有统计量必须使用占位符。
- 性别、年龄组和其他类别构成的人数与比例必须使用占位符。
- 方案定义的年龄范围属方案事实，仅从 facts 白名单引入。
- 实际最小值、最大值和组间差异属结果层，必须来自 datapack。
- 禁止“两组基本可比”、“基线均衡”或“无明显差异”的无条件套话。
- 如已预设基线平衡评价，仅陈述统计结果，不将非显著等同于等价。
- 如基线差异可能影响结果，只能在有已确认统计/医学分析时加 `[待医学负责人确认]`。
- 缺少关键基线变量时记录 source_gap，不从纳入标准推断实际分布。
- 表图号必须使用 `{{@ref:...}}`。

## 5. 推荐段落结构

- [段1] 分析人群与基线口径：引用 10.3 与 SAP，2–3 句。
- [段2] 年龄和性别：陈述每组关键统计量与构成，3–5 句。
- [段3] 其他人口学变量：只呈现对解释有用的变量，2–4 句。
- [段4] 疾病特征：按指定量表、病程和分层因素陈述，3–6 句。
- [段5] 主要终点的基线值：与后续协变量校正分析对应，3–5 句。
- [段6] 缺失、异常或不平衡现象：仅陈述事实，2–4 句。
- [段7] 表图引用：主文只提炼关键变量，1–2 句。
- 不要在正文罗列每一个表格单元格。
- 可将与主要终点解释无关的完整分布留在表中。
- 每段建议 3–6 句，超过 8 句时拆分。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 分析集与 10.3 不一致 | 从已确认 facts/SAP 派生，不重新定义 |
| 基线时点未说明 | 从方案与 SAP 精确引用基线算法 |
| 分母不清导致构成比无法对账 | 绑定 TFL 分母和非缺失计数 |
| 用 p 值证明“基线可比” | 只陈述数据，不把非显著当作等价证据 |
| 基线表与协变量模型值不同 | 对齐基线定义、访视窗口和异常值处理 |
| 缺失基线未报告 | 显示非缺失人数或缺失计数，不静默忽略 |
| 特殊人群分类与方案不一致 | 由 population.special_populations 路由并绑定定义 |
| 表号与第14章标题层级混淆 | 使用已确认独立发表号映射 |

## 7. 本节特有的易错点

- 基线值不一定是筛选值，常为首次给药前最后一次有效值。
- 多次基线记录可能采平均、最后值或特定访视，不得默认。
- 外用制剂研究的用药面积、皮损程度或皮肤状态可能是 PK 解释的关键基线变量。
- 年龄和性别是复合宽表字段时，不得将受试者级值展开入正文。
- 中位数与均值不能互换，范围与四分位数也不能互换。
- 性别或种族类别为空时，不得根据其他文件推断。
- 中心、国家或地区可能是分层因素，但不必然是正文需要详述的人口学变量。
- 不得为了简洁而省略影响主要分析的显著组间不平衡事实。
- 若分析集不同，FAS 和 mFAS 平行表不得共用 POP 键。
- 既往史 SOC/PT 和用药 ATC/药名行是数据驱动的，shell 阶段不建位置哈希键。
