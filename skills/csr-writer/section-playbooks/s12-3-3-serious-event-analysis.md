# §12.3.3 死亡、SAE 和其他重要 AE 的分析与讨论 playbook

> 本节综合经确认的关键事件事实，但不得替代医学负责人的判断。
> 与 §12.3.2 的个例叙述不同，本节关注事件模式、组间分布和研究层含义。

## 适用范围

- 仅在 §12.3.1 的关键事件集合和必要叙述已确认后起草。
- 可讨论死亡、SAE、其他重要 AE、停药事件和方案预设 AESI。
- 早期小样本研究应突出描述性局限，不作未经计划的比较推断。
- 无关键事件时仍须依赖完整集合零值，不能因没有叙述而判定无事件。
- 最终安全性结论仍归 §12.7 或第 13 章，本节不形成获益风险结论。

## 最低输入

- §12.3.1 三类经确认集合、计数和个体列表。
- §12.3.2 经医学负责人批准的叙述或叙述结论字段。
- §12.2 总体 AE、严重程度、后果和 AESI 汇总。
- 分析集、治疗组、暴露程度和随访时长。
- 医学审阅对事件模式的书面确认，不允许写手自行判断。

## 给写手的约束（不得写入正文）

- 事件模式只能基于经确认集合、叙述和汇总，不能由名称或单个病例外推。
- 不得在正文出现写手、证据包、绑定、条件分支或置信状态。
- 关键事件集合未闭合时只选用下一分区标准句，不形成安全性判断。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节关键事件分析待事件清单和医学审阅完成后补充。
- 本节结论基于已核实的关键事件资料，未涵盖尚未完成核实的事件。
- 现有资料不足以评价关键事件的分布特征及其临床意义。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §12.3.3 要求分析和讨论死亡、其他 SAE 及其他重要 AE。
- ICH E3 §12.3.1 提供本节使用的三个完整事件集合。
- ICH E3 §12.3.2 提供需要人工医学撰写的个例叙述。
- ICH E3 §12.2 提供常规 AE 背景和发生率口径。
- ICH E3 §12.1 提供解释事件所需的暴露程度。
- ICH E3 §13 承接研究层讨论和总体结论，避免本节越权。
- 规格 §1.2 禁止工具自主进行 AE 因果判定和获益风险结论。
- 规格 §1.2.1 要求结论性表述数据条件化并经医学确认。
- 国家药监局 2019 年第 88 号公告确立 ICH E3 中国 CSR 基线。
- CDE 2020 年第 5 号和 2023 年第 17 号为核查表已验证安全性依据。

- [ ] 各治疗组和剂量组的暴露程度是否足以支持描述。

- [ ] 所谓“模式”是否由预设汇总或医学审阅确认。
- [ ] 严重程度、严重性、后果和因果关系是否分别处理。
- [ ] 有无导致永久停药、临时停药、降量或退出的关键事件。
- [ ] AESI 是否按方案定义单独呈现。
- [ ] 重复事件和同一受试者多个事件是否避免重复计人。
- [ ] 事件时间与治疗暴露的关系是否只作客观陈述。
- [ ] 研究者因果评价是否保持原始强度。
- [ ] 申办方医学判断是否有批准文本和版本。
- [ ] 小样本或组间暴露不平衡是否限制解释。
- [ ] 缺失随访或未恢复事件是否明确说明。
- [ ] 跨节数值是否与 §12.2、§12.3.1 和 §12.7 一致。
- [ ] 本节是否避免独立写“风险可接受”或申报建议。

## 4. 数值红线与结论性表述规则

- 所有事件数、受试者数、比例、剂量、时间和暴露结果使用占位符。
- 模式识别使用的阈值、排序和组间差异也必须来自预设绑定。
- 不得根据事件发生在给药后推断“与研究药相关”。
- 不得把研究者评价汇总为更强的申办方因果结论。
- 不得将“未观察到聚集”写成“已排除风险”。
- 任何“未见一致模式”“未提示新风险”等判断均需医学批准且标待确认。
- 有死亡、SAE 或停药事件时必须先逐类陈述客观事实，再给受控判断。
- 关键计数、随访状态或暴露信息缺失时，不生成事件模式判断。
- 本节不得使用总体“耐受性良好”token 替代逐类分析。
- 获益风险、推进下一阶段或申报建议属于规格红线，始终禁止。
- 小样本下不以未显著为“无差异”，不以零事件推导风险不存在。

## 5. 推荐段落结构

- [段1] 分析范围：2–4 句，说明分析集、截止日、暴露和事件集合。
- [段2] 死亡：2–5 句，陈述完整集合、时间和组别；无事件须有零值绑定。
- [段3] SAE：3–6 句，区分受试者与事件、SOC/PT、转归和措施。
- [段4] 其他重要 AE：3–6 句，按预设类别和后果呈现。
- [段5] AESI/停药/退出：适用时 3–6 句，不与常规 AE 混写。
- [段6] 暴露与时间分布：2–5 句，仅作客观描述。
- [段7] 跨组或剂量组观察：3–5 句，先说明样本和暴露限制。
- [段8] 医学综合：1–3 句，使用批准文本或待医学确认标记。
- [段9] 局限：2–4 句，说明样本量、随访、缺失或组间不平衡。
- 每段 3–6 句；不得逐篇复述 §12.3.2 叙述。
- 关键事件少时可合并事实段，但仍应保留集合边界。

### 结论段顺序硬规则

1. 先陈述死亡。
2. 再陈述 SAE。
3. 再陈述导致停药/退出和其他重要 AE。
4. 再陈述未解决或随访中事件。
5. 最后才放 `[待医学负责人确认]` 的综合句。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 讨论段只是重复个例叙述 | 按集合、模式、暴露和局限组织 |
| 小样本无事件被解释为无风险 | 陈述零值和样本局限，不外推 |
| 有 SAE 仍先写“耐受性良好” | 强制关键事件事实先于判断句 |
| 事件时间顺序被当作因果 | 仅陈述时间，因果取批准评价 |
| 受试者数和事件数混写 | 独立语义角色和句内口径标签 |
| 与 12.2 总体概要不一致 | 发布前做跨节关键计数对账 |
| 与 12.1 暴露脱节 | 每个组间观察同时核对暴露 |
| 忽略未恢复或随访中事件 | 将截止日状态设为必答字段 |
| 把“未显著”写成“相当” | 禁止从非显著性作等同性解释 |
| 事后筛选事件模式未标明 | 非预设观察强制标“探索性/事后” |
| 研究者因果评价被增强 | 保留原始分类和主体 |
| 直接给获益风险结论 | 留给第 13 章人工确认且仍受红线 |

## 7. 本节特有的易错点

- 事件率受暴露时长影响，短暴露组不能直接与长暴露组比较。
- 剂量组样本数不同会造成原始事件数误导。
- SOC/PT 层级聚集可能由同一受试者多个事件造成。
- SAE 的“相关”是评价字段，不是统计显著性结果。
- 其他重要 AE 的类别可与 SAE、停药和 AESI 重叠。
- 事件未恢复可能因随访截止而非持续恶化。
- 开放标签或解盲后的因果评价可能受信息影响，仅可客观说明。
- 局部反应高频不等同系统性安全风险，也不能自动视为轻微。
- 早期研究的剂量递增规则会造成各组观察期和人数不平衡。
- 多事件叙述合并会遮蔽事件计数，须回到结构化集合核对。
- “无新信号”需要外部/既往证据，当前研究单独不能自动得出。
- 第 13 章必须派生本节已确认内容，不得重新选择事件。
