# §13 讨论和总体结论——从已确认正文派生 playbook

> §13 不是独立写手入口。只能从已经确认并冻结的正文派生，
> 不得重新读取全量 TFL、选择新结果或形成自主获益风险结论。

## 适用范围

- 用于整项研究的关键发现、局限和与研究目标对应的总体总结。
- 输入只能是已确认的 §10–§12 正文、确认状态和已解决交叉引用。
- Synopsis 结论从本节及已确认正文进一步确定性派生，不独立起草。
- 若关键结果节未确认，本节保持 source_gap 或待确认，不提前形成判断。
- 早期研究应按探索性目的和样本限制陈述，不套用确证性结论模板。

## 最低输入

- 冻结且人工确认的 §10.1、§10.2、§10.3 受试者与分析集内容。
- 冻结且确认的 PK、疗效/PD、暴露、安全性和关键事件正文。
- 方案预设目标和终点层级，以及 SAP 的分析定位。
- 每节来源台账、未解决 source_gap 和关键人工确认状态。
- 研究局限清单，由方案/SAP/已确认正文事实支持。

## 给写手的约束（不得写入正文）

- 仅使用已在经确认正文出现的结果；不得重新选择 TFL 数值或引入新结果。
- 不得在正文提及写手、派生流程、证据包、绑定、置信状态或缺口代码。
- 任一关键结果未确认时只选用下一分区标准句，不形成总体或获益风险判断。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本研究总体结论待主要终点、关键安全性事件和药代动力学结果完成确认后补充。
- 本节结论基于已确认的正文结果，未引入正文未报告的新结果。
- 现有资料不足以形成总体获益风险结论，相关判断待医学负责人确认。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §13 规定讨论和总体结论，并要求结合研究目标解释结果。
- ICH E3 §2 Synopsis 需与正文结论一致，不能独立产生新判断。
- ICH E3 §8 研究目标与 §9.5 终点为讨论组织轴。
- ICH E3 §10–§12 提供受试者、疗效/临床药理和安全性事实。
- 规格 §1.2 禁止工具自主形成获益风险结论和申报建议。
- 规格 §1.2.1 允许的数据条件化结论仍必须待医学负责人确认。
- 规格 §4 P6 要求双向追溯，讨论中的每项结果必须回到已确认正文/TFL。
- 国家药监局 2019 年第 88 号公告确立 ICH E3 中国 CSR 基线。
- `CDE申报要求核查表.md` 没有授权工具自动给出“符合 CDE”结论。
- QC 结论只能写“未发现某类问题”，不得写“申报就绪/可以递交”。

## 2. 必须回答的问题清单

- [ ] 研究主要目的和探索性目的分别是什么。
- [ ] 每个目的对应哪些已确认结果节。
- [ ] 研究实际入组、治疗和分析人群是否影响解释。
- [ ] 重要方案偏离和缺失数据是否影响结果可解释性。
- [ ] PK/PD/疗效主要发现是否仅引用已确认正文。
- [ ] 安全性讨论是否先覆盖死亡、SAE、停药和重度事件。
- [ ] 局部耐受性与编码 AE 是否保持概念分离。
- [ ] 外用制剂低系统暴露是否同时说明 BLQ、可定量时点和参数可计算性。
- [ ] 结果是否与方案预设终点层级一致。
- [ ] 事后或探索性分析是否明确标注。
- [ ] 组间比较是否受样本量、暴露和设计限制。
- [ ] 所有关键结论是否在对应正文已有确认版本。
- [ ] 是否存在未解决 source_gap，如何限制结论。
- [ ] 是否避免跨研究比较或外部证据的无来源引入。
- [ ] 是否避免自主 AE 因果判断。
- [ ] 是否避免“疗效确切”“风险可接受”“建议推进”等红线。
- [ ] Synopsis 是否从本节和正文派生且无新增结果。
- [ ] 每个结论句是否有 claim ledger/来源元数据。

## 4. 数值红线与结论性表述规则

- §13 不新建数值占位符；只能复用已确认正文中的结果引用或非数值概括。
- 若确需显示数字，必须引用正文已确认的同一语义键，不得创建第二份绑定。
- 不得为“简洁”改写、四舍五入或选择不同分析集的数值。
- 不得把探索性结果改写为确证性结果。
- 不得从非显著性推导等效、无差异或无效。
- 不得自动作 AE 因果判定、获益风险判断或推进开发建议。
- “达到主要目的”“总体耐受性良好”等必须由上游数据条件化结论支持。
- 有 SAE、死亡、停药或重要异常时，必须在安全性判断前陈述。
- 关键正文或人工确认缺失时，删除判断句并输出待数据/待确认提示。
- 所有综合判断保留 `[待医学负责人确认]`、`confidence=inferred`、
  `needs_human=true`，直至人工放行。
- QC 不得把无内部矛盾升级为“符合 CDE 要求”或“申报就绪”。

## 5. 推荐段落结构

- [段1] 研究定位：2–4 句，重述研究设计、主要目的和探索性边界。
- [段2] 受试者与数据解释基础：3–5 句，处置、分析集、偏离和缺失。
- [段3] 主要临床药理/PK 发现：3–6 句，引用已确认 §11.5。
- [段4] 探索性疗效/PD 发现：适用时 3–6 句，明确探索性。
- [段5] 暴露和常规安全性：3–6 句，先给暴露背景再给 AE。
- [段6] 死亡、SAE、停药和其他重要事件：3–6 句，顺序不可后置。
- [段7] 实验室、生命体征、心电图和局部耐受性：3–6 句，按路由取舍。
- [段8] 一致性与局限：3–6 句，覆盖样本量、随访、缺失和设计限制。
- [段9] 总体结论：1–3 句，仅复用已确认数据条件化结论并待医学确认。
- 每段通常 3–6 句；不得把所有结果压成两句套话。
- 无对应模块的内容不出现空段；有 source_gap 的内容要说明限制。

### 总体结论的生成顺序

1. 确认主要目的对应的结果节已经人工放行。
2. 确认安全性五项关键绑定和 §12.3 关键事件已放行。
3. 确认局限段包含未解决缺口。
4. 复用上游批准措辞，不扩大确定性。
5. 添加 `[待医学负责人确认]`，等待最终签核。
6. 再由确定性装配派生 Synopsis 对应句。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| §13 独立读取 TFL 后重新选结果 | 只接收已确认正文和来源元数据 |
| 讨论只有结果复述，没有局限 | 将设计、样本、缺失和暴露限制设为必答 |
| 探索性结果写成“疗效确切” | 标明探索性且禁止确证性措辞 |
| 有 SAE/停药仍先写耐受性良好 | 关键事件段必须在总体判断前 |
| 外用 PK 只写“系统暴露低” | 同步复用 BLQ、可定量时点、参数可算性和 LLOQ 局限 |
| 将无显著差异写成相当 | 禁止从非显著性作等同性解释 |
| 与 Synopsis 出现不同结论 | Synopsis 从确认正文和 §13 派生 |
| 新引外部研究但无来源 | 本 playbook 不接外部证据；需另行已审来源流程 |
| 对 AE 自主判定因果 | 只保留研究者/医学负责人批准主体 |
| “未发现问题”被升级为“符合 CDE” | QC 权限固定为问题类别检查 |
| source_gap 被静默省略 | 局限段必须列出对解释的影响 |
| 结论性句未标人工确认 | 元数据和正文双重门禁 |

## 7. 本节特有的易错点

- “讨论”不等于可以自由推理，仍受闭集证据约束。
- 跨节同一数值只允许一个真相源，不得复制后手工维护。
- PK 目的、探索性疗效目的和安全性目的的证据强度可能不同。
- 早期研究未设确证性终点时不能写“达到疗效终点”。
- 小样本无 SAE 不等于排除低频风险。
- 局部耐受性良好不能自动外推总体安全性良好。
- 系统暴露低不能自动推导无系统风险。
- 组间不平衡可能源于递增设计，不应写成随机比较结论。
- 事后分析即使数值有利也必须明确标注。
- 讨论中的“与既往一致”需要经审外部证据，本轮默认不自动生成。
- 结论段是同级最后，但不改变既定章节编号。
- clean 版只在所有待确认和 source_gap 达到发布门槛后生成。
