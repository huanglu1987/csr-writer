# §11.5.5 达峰时间与系统暴露 playbook

## 适用范围

- 用于描述 Tmax、Cmax、AUC 及它们对系统暴露的支持范围。
- 仅在参数可计算且来源已确认时呈现具体结果。
- 外用制剂不预设“系统暴露低”。
- 不可计算时必须与 BLQ、LLOQ 和采样覆盖联系说明。

## 给写手的约束（不得写入正文）

- Tmax、Cmax 和 AUC 的取值不得互换。
- 不得由浓度图手工估计 Tmax 或 Cmax。
- 不得将一个受试者的参数写成组汇总值。
- 不得用 BLQ 或无法计算替代暴露结论。
- 不得自行选择算术均值或几何均值。
- 不得把 D1 参数与 D28 参数混写。
- 不得在正文中出现写手、绑定、数据包、映射或置信度。
- 参数、单位、时间、例数和变异系数全部走占位符。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 达峰时间和系统暴露参数待相应统计结果到位后补充。
- 当前可定量数据不足以计算完整暴露参数。
- 本节结果仅涉及已可计算的 PK 参数。
- 现有采样覆盖不足以描述完整的达峰和消除过程。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`和其他“XX 性为”。
- 「经审核」「按预设」各自每节至多 1 次。
- 每段至多 1 个分号。
- 单句不超过 60 字。
- 限定条件统一放在段末。
- 优先写“Cmax 与 AUC 均可计算”，不写字段式状态。
- 参数多时用平行短句，不用连续分号。
- 不重复在每句后附加方法限制。

## 1. 本节的权威依据

- ICH E3 §9.5.4 要求说明药物浓度测定。
- ICH E3 §11 要求报告结果并说明分析人群与方法。
- ICH E3 Q&A Q1/Q4 允许为 PK 结果设置正式扩展节。
- 国家药监局2019年第88号公告是已验证的中国实施依据。
- 本节由 M-PK-NCA 或 M-TOPICAL-PK 模块激活。
- 外用 PK 的目的是界定系统暴露，不是预设达到低暴露结论。
- 参数真相源是已确认 NCA TFL 和 SAP。
- 核查表未验证的专项文号不得自行增补。

## 4. 数值红线与结论性表述规则

- Cmax、Tmax、AUC、例数、变异系数和区间全部走占位符。
- `t1/2`、`AUC0-∞` 等参数 token 只做名称例外，不进入数值白名单。
- “Cmax 与 AUC 均可计算”必须由两个已确认状态生成。
- 不可计算时必须呈现具体原因。
- 参数较小不得直接改写为系统暴露低。
- 组间差异未经预设分析时不作显著性解释。
- 外用制剂的暴露结论必须同时考虑 BLQ、LLOQ 和覆盖。
- 结论只在 11.5.10 通过条件化规则生成。
- 关键绑定缺失时只生成待数据提示。
- 图表引用只使用 `{{@ref:...}}`。

## 5. 推荐段落结构

- [段1] 说明分析集、参数定义和统计量，3–5 句。
- [段2] 呈现单次给药的 Cmax 和 Tmax，3–5 句。
- [段3] 呈现单次给药的 AUC，3–5 句。
- [段4] 呈现稳态阶段对应参数，3–6 句。
- [段5] 说明各参数可计算人数，2–4 句。
- [段6] 说明不可计算参数及原因，2–5 句。
- [段7] 结合 BLQ、LLOQ 和采样覆盖写限制，3–5 句。
- 不在本节展开剂量比例性或蓄积分析。
- 每段只提炼对暴露判读必要的参数。
- 无稳态数据时不生成第4段。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 参数没有单位 | 单位与参数绑定并经核对 |
| Tmax 用均值描述 | 遵循 SAP 的中位数和范围规定 |
| 混淆 AUC0-t 和 AUC0-∞ | 保留完整参数名称 |
| 不可计算却不说原因 | 绑定 BLQ、可定量点和采样覆盖 |
| 用参数小推导暴露低 | 只报参数，结论留给受控规则 |
| 将 D1 与 D28 混写 | 按 STAGE 分段并引不同表 |
| 忽略可计算人数 | 每类参数同时核对 N |
| 只写均值不说变异 | 按 SAP 提供 SD 或 CV% |

## 7. 本节特有的易错点

- Tmax 受采样时点密度限制，不是连续时间真值。
- Cmax 是观察或计算参数，不可从组均曲线反推个体 Cmax。
- AUC0-∞ 需要可靠的终末相估计。
- 外用低暴露数据中 AUC0-∞ 可能大量不可计算。
- 几何均值与 CV% 必须对应同一可用人群。
- 同一参数的 N 可在组内不同于 PK 分析集总人数。
- 采样未覆盖真实峰值时，观察 Cmax 可被低估。
- 终末相点数不足时，t1/2 和 AUC0-∞ 均可受影响。
- 参数单位可随分析物和时间尺度变化。
- 本节不做系统暴露的临床意义判定。
