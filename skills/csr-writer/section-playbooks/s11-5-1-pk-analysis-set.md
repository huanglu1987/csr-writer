# §11.5.1 PK 分析集 playbook

## 适用范围

- 用于说明血药浓度和 PK 参数分析所用人群。
- 分析集名称由项目 SAP 决定，不预设 PKS、PKCS 或 PKPS。
- 本节只呈现人群定义与实际纳入情况。
- 实际 PK 结果放在 11.5.2–11.5.10。

## 给写手的约束（不得写入正文）

- 分析集名称和定义必须逐项来自 SAP 或已确认事实。
- 不得将 PKCS、PKPS 或 PKS 自行视为同一人群。
- 不得根据表中人数反推纳入标准。
- 不得将排除理由改写成医学解释。
- 不得在正文中提及证据包、绑定、语义键或写作流程。
- 如果 SAP 与方案名称不同，只记录差异并进入人工确认。
- 不得用通用的 FAS/PPS/SS 枚举替换项目原名。
- 纳入人数、排除人数和比例必须使用占位符。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- PK 分析集的实际纳入情况待相应统计结果到位后补充。
- 本节仅说明已确认的分析集定义。
- 个别受试者的纳入状态尚需依据分析集清单确认。
- 不同 PK 分析集之间的差异待相关清单完成后补充。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`和其他“XX 性为”。
- 「经审核」「按预设」各自每节至多 1 次。
- 「预设」只用于区分预先规定与事后处理。
- 每段至多 1 个分号，超出时拆成完整句。
- 单句不超过 60 字。
- 边界声明放在段末，不逐句重复。
- 优先使用“共 N 例纳入 X 分析集”的自然句式。
- 避免把分析集定义写成字段罗列。

## 1. 本节的权威依据

- ICH E3 §11 要求清楚说明结果分析所用的受试者人群。
- ICH E3 Q&A Q1 允许在疗效与安全性人群差异较大时调整章节位置。
- 本工具将所有分析集统一定义于 10.3。
- 11.5.1 只说明与 PK 结果直接相关的人群适用性。
- ICH E3 §9.5.4 要求说明药物浓度测定。
- 国家药监局2019年第88号公告是核查表中已验证的 ICH E3 中国实施依据。
- 分析集的真相源是定稿 SAP、分析集清单和已确认 TFL。
- 未在 CDE 核查表中验证的文号不得自行增补。

- [ ] 各组纳入人数是否与 10.3 一致。
- [ ] 分析集差异是否影响后续参数结果。

## 4. 数值红线与结论性表述规则

- 纳入、排除和分组人数全部通过占位符。
- 分析集定义属方案/SAP 事实，不得根据结果反推。
- “全部”“多数”或“大部分”需要可追溯的分母和结果。
- 不得把一个分析集的人数代入另一个分析集。
- 分析集较小不得自动解释为数据质量问题。
- 排除原因仅客观呈现，不自主作医学判断。
- 本节不得产生暴露、疗效或安全性结论。
- 如果人数绑定缺失，只使用标准缺口句。
- 组别语义必须与 10.1 及分组例数账户一致。
- 所有表号必须使用 `{{@ref:...}}`。

## 5. 推荐段落结构

- [段1] 说明 PK 分析集原名及用途，2–3 句。
- [段2] 忠实转述纳入与排除标准，3–5 句。
- [段3] 呈现实际纳入人数及分组情况，2–4 句。
- [段4] 说明各 PK 分析集之间的差异，2–4 句。
- [段5] 客观列出需要说明的特殊排除，2–4 句。
- [段6] 在段末说明人群差异对阅读后续 PK 结果的限制。
- 不重复抄写 10.3 的全部定义。
- 不在本节评论参数结果。
- 如果只有一个 PK 分析集，合并第4段。
- 如果无特殊排除，不生成空段。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 分析集名称与 SAP 不一致 | 保留 SAP 原名和大小写 |
| 把 PKCS 与 PKPS 混为一组 | 按用途分开定义和人数 |
| 从 TFL 人数反推纳入标准 | 纳入标准只取 SAP |
| 人数与 10.3 不一致 | 发布前做跨章对账 |
| 未说明特殊排除 | 引用已确认清单并给出原因 |
| 将排除解释为不耐受 | 只客观记录，不作因果解释 |
| 忽略采样偏离对分析集的影响 | 对照 SAP 排除规则和偏离清单 |
| 用统计结果替代人群定义 | 先写定义，再写实际纳入 |

## 7. 本节特有的易错点

- “有浓度数据”与“可进行 PK 参数分析”不是同一标准。
- 单个可定量时点通常不足以计算 AUC 或终末相参数。
- 实际采样时间偏离可能改变受试者的参数适用性。
- 外用制剂的低浓度数据不能作为放宽纳入标准的理由。
- 分析集的大小写和前缀是语义的一部分。
- mFAS、PKCS、PKPS 等项目原名不得被强制全大写。
- 一个受试者可同时属于多个 PK 分析集。
- 人群重叠不意味两个分析集可互换。
- 任何事后排除都必须保留决策记录。
- 本节不给出“PK 结果可靠”类质量判断。

## 8. 自然句式库

- 共 `{{...}}` 例受试者纳入 PK 浓度分析集。
- 其中 `{{...}}` 例进一步纳入 PK 参数分析集。
- PK 分析集按 SAP 规定定义。
- 各治疗组的纳入情况详见表 `{{@ref:...}}`。
- 两个分析集的差异主要源于已确认的排除规则。
