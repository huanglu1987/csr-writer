# §11.3 治疗依从性的测量——结果起草 playbook

> 适用于方案和 study_facts 已确认需要评价治疗依从性的研究。
> 本节回答实际依从情况；§9.4.8 只描述计划的方法，两者不得互相替代。

## 适用范围

- 口服、注射、外用、吸入和眼用制剂均可使用，但计量单位须由方案定义。
- 外用制剂应区分给药次数、实际用量、涂布面积和研究者确认的给药记录。
- 有电子监测、药物计数、日记卡或药物浓度佐证时，分别说明证据角色。
- 未设计依从性评价时，本节按路由裁剪，不得从处置或暴露表推算。
- 依从性与方案偏离、暴露程度和疗效分析集的关系应交叉核对。

## 最低输入

- 方案 §9.4.8 或项目等价章节中的依从性定义、计算公式和允许范围。
- SAP 的汇总方法、分析集、缺失记录和异常记录处理规则。
- 已确认 tfl_map 中的依从性汇总表及必要的个体列表索引。
- 药物发放/回收、日记卡或电子给药记录的经审核结果。
- 如使用药物浓度佐证，须明确其仅为支持性证据，不能自动等同依从。

## 给写手的约束（不得写入正文）

- 依从性算法、分母和异常记录处理须沿用经审核定义，不得自行重算或改写。
- 不得在正文描述生成过程、证据包、语义键或数据来源的技术状态。
- 未提供实测结果时只选用下一分区标准句，不得从药物回收或浓度间接推定。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节治疗依从性情况待相应统计结果到位后补充。
- 本节结论基于已核实的给药记录，未涵盖记录范围之外的情形。
- 现有资料不足以评价治疗依从性及其对结果解释的影响。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §9.4.8 规定报告计划采用的治疗依从性措施。
- ICH E3 §11.3 规定报告治疗依从性的实际测量结果。
- ICH E3 Q&A Q2 明确 Synopsis 应包含治疗依从性的重要信息。
- ICH E3 §16.2.5 对依从性和/或药物浓度个体数据给出附录位置。
- ICH E3 §10.2 和 §10.3 为退出、方案偏离和分析集交叉核对提供结构位置。
- 国家药监局 2019 年第 88 号公告确立 ICH E3 为中国 CSR 结构基线。
- `CDE申报要求核查表.md` 未列出本节专属的已验证 CDE 文号，不得自行补写。
- 研究方案、SAP 和经确认 tfl_map 是项目层权威来源，优先于行业默认公式。

## 2. 必须回答的问题清单

- [ ] 方案如何定义依从性，分子、分母和评价窗口分别是什么。
- [ ] 计划给药次数或计划用量如何计算，是否扣除暂停期。
- [ ] 实际给药来自回收计数、日记卡、电子记录还是研究者记录。
- [ ] 依从性评价使用哪个分析集，是否与 §10.3 名称一致。
- [ ] 依从性可评价受试者的判定规则是什么。
- [ ] 缺失给药记录如何处理，是否计入分母。
- [ ] 超额给药、补服、漏用和部分给药如何处理。
- [ ] 允许范围是否在方案中预设，而非结果后选择。
- [ ] 各治疗组的依从性概况是什么。
- [ ] 低于或高于预设范围的受试者是否有经确认计数。
- [ ] 是否存在按访视或阶段汇总，阶段边界是否清楚。
- [ ] 外用制剂的涂布面积、频次和用量是否分别核对。
- [ ] 依从性异常是否已作为重要方案偏离或其他偏离分类。
- [ ] 依从性异常是否影响分析集纳入，依据是否来自 SAP。
- [ ] 药物浓度是否只作佐证，是否避免反向推断依从性。
- [ ] 个体数据是否按要求放在 16.2.5，而非正文逐例罗列。
- [ ] 正文是否只提炼关键结果并引用支持表。
- [ ] 任何“依从性良好”类判断是否满足数据条件并待医学确认。

## 4. 数值红线与结论性表述规则

- 依从性百分比、给药次数、用量、持续时间、范围界值和受试者例数全部用占位符。
- 不得写“多数”“大部分”“接近全部”等中文模糊量词替代占位符。
- 计划值属于方案事实，但正文引用时仍应从已确认 facts 白名单或绑定取得。
- 依从性公式不可由写手重算；由确定性脚本或已确认 TFL 给出显示值。
- 同一受试者的次数依从性与用量依从性不得互换。
- 任何“总体依从性良好/可接受”均为结论性表述，必须标 `[待医学负责人确认]`。
- 仅当所有治疗组的可评价人数、中心趋势、预设范围外人数和缺失记录均已绑定时，
  才允许进入数据条件化判断。
- 存在大量缺失、范围外记录或组间明显不平衡时，必须先陈述这些事实并改变措辞。
- 关键绑定缺失时不生成判断句，改写为“待依从性结果到位后评价”。
- 不得把依从性高推导为疗效好，也不得把药物浓度低推导为未用药。
- 结论不得形成方案偏离严重性判断，除非该分类已由授权流程确认。

## 5. 推荐段落结构

- [段1] 评价方法与分析集：2–4 句，说明方法、窗口、公式来源和分析集。
- [段2] 数据完整性：2–4 句，说明可评价范围、缺失记录和异常记录处理。
- [段3] 总体结果：3–6 句，呈现各组关键中心趋势和范围，引用汇总表。
- [段4] 范围外情况：2–5 句，分开低依从、超额给药和记录缺失。
- [段5] 阶段或访视结果：仅方案预设且有绑定时写，3–5 句。
- [段6] 与偏离/分析集关系：2–4 句，只陈述经确认事实。
- [段7] 支持性药物浓度：如适用，2–4 句，明确不能单独证明依从性。
- [段8] 条件化结论：1–3 句，标记待医学确认；绑定缺失则写数据提示。
- 每段通常 3–6 句，超过 8 句应拆分。
- 不逐例抄写给药记录；个体数据留在 16.2.5。
- 不重复 §9.4.8 的整段方法，只保留理解结果必需的定义。

### 段落措辞边界

- 首段使用“依从性按方案预设方法评价”，不得写“证明受试者遵从治疗”。
- 结果段直接陈述例数、比例或“记录显示”的事实，不得使用“患者积极配合”。
- 缺失段明确“记录缺失”，不得改写为“未给药”。
- 偏离段注明分类来源，不得由依从性数值自行判定重要偏离。
- 结论段不得连接到疗效或获益风险判断。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 只给平均依从率，不说明公式 | 首段强制列出公式来源、窗口和单位 |
| 分母未扣除经方案允许的暂停期 | 由 SAP 确认分母规则，写手不重算 |
| 将缺失日记记作未给药 | 分开“缺失记录”和“确认未给药” |
| 外用制剂只按回收重量判断 | 同时核对频次、涂布面积和记录方法 |
| 依从性范围在看过结果后设定 | 只使用方案/SAP 预设界值 |
| 把药物浓度低解释为不依从 | 将浓度限定为支持性证据并说明局限 |
| 与 10.3 分析集人数不一致 | 发布前做组别和分析集账户对账 |
| 与 10.2 方案偏离分类矛盾 | 只引用已确认偏离表，不自行分类 |
| 逐例罗列导致正文失焦 | 正文提炼，个体数据转 16.2.5 |
| “依从性良好”没有数据条件 | 关键绑定齐全并标待医学确认，否则不判断 |
| 次数依从性和用量依从性混用 | 在语义键中编码 `MEASURE=` 维度 |
| 多阶段研究把阶段合并 | 使用 `STAGE=` 区分，不能按位置合计 |

## 7. 本节特有的易错点

- 依从性可能超过上限，不应自动截断为上限值。
- 研究药物回收差额不必然等于实际使用量，需按项目方法定义。
- 开封、损耗、挤出后未使用等情形可影响外用制剂重量法。
- BID 与 QD 组的计划次数不同，不能比较原始给药次数。
- 不同浓度组的用量和有效成分量是不同维度。
- 治疗中断可能是方案允许、安全性处置或不依从，必须区分。
- 依从性分析集可不同于 FAS、mFAS、SS，不能预设枚举。
- 日记卡补录与实时电子记录的证据强度不同，但写手不自行评级。
- 多中心差异只有在预设分析或数据核查支持时才可陈述。
- 药物浓度受吸收、采样和分析方法影响，不能作为单一依从性真相源。
- 个体极端值如有经批准的来源说明，可通过事实卡受限转述；无来源时明确留缺口，不推断原因。
- shell 阶段数据驱动行应延后，结果阶段按真实语义建立键。
