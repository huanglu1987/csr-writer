# §12.4.2 临床实验室参数评价——共享结果 playbook

> 供 §12.4.2.1 随时间变化、§12.4.2.2 个例患者变化、
> §12.4.2.3 个例临床重要异常值共用。

## 适用范围

- 仅呈现方案预设或医学审阅确认的临床实验室安全性结果。
- 实验室原始值、变化值、分级转换和临床重要异常分别处理。
- 全部个体测量值列表归 16.2.8（按监管要求）；异常值列表归 14.3.4。
- 不得把统计异常自动判为临床重要，也不得把参考范围内判为无临床意义。
- 多实验室研究须说明单位、参考范围和标准化方法。

## 最低输入

- 方案的实验室项目、时点、采样和复查规则。
- SAP 的基线定义、单位转换、参考范围、分级和缺失处理。
- 实验室供应商/中心实验室的单位、正常范围、LLOQ/ULOQ（如适用）。
- 经确认的时间趋势、转移表和临床重要异常个体列表。
- 医学负责人对临床重要异常的确认结果。

## 给写手的约束（不得写入正文）

- 统计异常、分级异常和临床重要异常必须分开，不能自动互相判定。
- 不得在正文暴露写手、映射、绑定、占位符或人工审核流程。
- 单位、参考范围或医学判定不足时只选用下一分区标准句。

## 证据不足时的标准表述（可写入正文，须按此措辞）

- 本节实验室参数变化情况待相应统计结果到位后补充。
- 本节临床重要异常值情况待医学审阅完成后补充。
- 本节结论基于已完成核实的实验室结果，未涵盖单位或参考范围尚未统一的资料。

## 文风规范

- 禁用表达：`汇总为`、`汇总结果为`、`可计算性为`及其他“XX 性为”字段式句法。
- 「经审核」「按预设」各自每节至多 1 次，仅用于首次界定来源；后文直接引用方案或 SAP。
- 每段至多 1 个分号，超过时拆为完整句。
- 单句不超过 60 字；较长限定条件应拆出并放在段末。
- 边界声明放在段末，不逐句重复免责或核查范围。
- 优先使用“主语 + 动作 + 结果”的完整句，不逐项念出角色名称和值。
- 零事件表述只能由数据条件化规则生成，不得在起草正文中硬编码。

## 1. 本节的权威依据

- ICH E3 §12.4 要求报告临床实验室评估。
- ICH E3 §12.4.1 区分个体测量值列表和异常实验室值列表。
- ICH E3 §12.4.2.1 要求评价随时间变化的实验室数值。
- ICH E3 §12.4.2.2 要求评价个例患者变化。
- ICH E3 §12.4.2.3 要求评价个例临床重要异常值。
- ICH E3 §14.3.4 是所有监管机构要求的异常实验室值个体列表。
- ICH E3 §16.2.8 是按患者列出的全部个体实验室测量值列表，按要求提供。
- ICH E3 §16.1.10 是实验室间标准化方法和质量保证文件（如使用）。
- 国家药监局 2019 年第 88 号公告确立 ICH E3 中国 CSR 基线。
- `CDE申报要求核查表.md` 未列本节专属已验证文号，不得自行补文号。

## 4. 数值红线与结论性表述规则

- 原始值、变化值、正常范围、分级、例数、比例和访视时间全部用占位符。
- 单位也必须与绑定元数据一致，不能由写手在数值后手工补猜。
- 正常范围界值不得写入静态白名单替代数据绑定。
- `t1/2`、`AUC0-∞` 等 PK 参数例外与本节实验室数值无关，不能误用放行。
- “无临床重要变化”“无剂量相关趋势”均为医学结论，必须待人工确认。
- 只有经医学确认的临床重要异常集合可支持“临床重要”表述。
- 缺少单位、参考范围、基线或复查状态时，不生成临床意义判断。
- 统计显著变化不能自动写成临床重要。
- 参考范围内变化不能自动写成无临床意义。
- 由实验室异常推导 AE 或因果关系属于红线，禁止。
- 结论段必须先陈述关键异常和局限，再放 `[待医学负责人确认]`。

## 5. 推荐段落结构

### §12.4.2.1 随时间变化的实验室数值

- [段1] 分析集、项目、单位、基线和访视窗：3–5 句。
- [段2] 血液学主要趋势：3–6 句，引用时间趋势表。
- [段3] 生化主要趋势：3–6 句。
- [段4] 尿液或其他项目：适用时 2–5 句。
- [段5] 分级/参考范围转移：3–5 句。
- [段6] 数据完整性和局限：2–4 句。

### §12.4.2.2 个例患者变化

- [段1] 个体变化筛选规则：2–4 句。
- [段2] 基线至最差治疗后变化：3–6 句。
- [段3] 复查、恢复或持续状态：2–5 句。
- [段4] 个体列表引用：1–3 句，不逐例抄正文。

### §12.4.2.3 个例临床重要异常值

- [段1] 临床重要性确认方法和责任人：2–4 句。
- [段2] 经确认集合和涉及项目：3–6 句。
- [段3] 与 AE/停药/复查的客观对应：2–5 句。
- [段4] 医学评价：1–3 句，必须待医学确认。
- 每段 3–6 句，多个实验室域应分段而非列举全部参数。

## 6. 常见退审问题

| 问题 | 如何规避 |
|---|---|
| 只报均值，遗漏个体异常 | 同时覆盖趋势、转移和个体重要异常 |
| 多实验室单位混合 | 绑定实验室、单位、范围和版本 |
| 正常范围变化被写成无意义 | 临床意义只来自医学确认 |
| 统计显著被写成临床重要 | 分开统计结果和医学评价 |
| 基线定义与 SAP 不一致 | 从 SAP/facts 取唯一基线规则 |
| 用末次访视代替最差值 | 按预设算法绑定，不能临时选择 |
| 缺失样本被写成正常 | 明确缺失和无效结果，不推断 |
| 复查结果未与原异常关联 | 使用受试者/项目/访视语义路径 |
| 14.3.4 只放“临床重要”而漏异常值 | 按 E3 要求核对完整异常列表范围 |
| 16.2.8 被误当必随 CSR 提交 | 在 16.0 标注条件性状态 |
| 实验室异常自动转成 AE | 只有 AE 数据中已有事件才链接 |
| 逐参数抄表导致正文失焦 | 只提炼预设/医学重要趋势，完整表留附件 |

## 7. 本节特有的易错点

- 同一参数不同实验室的参考范围可能不同，不能只比较绝对值。
- 单位换算前后的小数精度和正常范围必须一致。
- 基线异常至正常与正常至异常是不同转移方向。
- “最差值”方向依参数而异，不能一律取最大值。
- 分级恶化可能发生在绝对值仍接近参考范围时，需按规则呈现。
- 溶血、脂血和样本质量标志不能静默丢弃。
- BLQ/ULOQ 结果属于非数值类别与界限信息，不能伪造具体值。
- 复查缺失不等于异常持续，也不等于恢复。
- 临床重要性可由研究者和医学监查分别评价，差异需人工处理。
- 实验室异常与并发疾病、合并用药的关系不能由工具推断。
- 妊娠试验等特殊检验应按方案保密和显示规则处理。
- 结果 TFL 的数据驱动参数行应以真实项目名建键，不使用位置哈希。
